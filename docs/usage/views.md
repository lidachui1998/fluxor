# 面板界面与操作

本页面详细介绍 Fluxor 网页控制面板中，各个功能界面的具体按钮操作与使用细节。

---

## 1. 概览 (Overview)
提供底层内核健康状况与网络流量波动的实时监控。

* **速率与吞吐**：实时展示当前瞬时的上传/下载网速（KB/s 或 MB/s），以及本次运行以来的累计上传和下载流量。
* **信息卡片**：展示内核的内存占用、活动连接数、内核版本，以及外部控制面板入口。
* **自绘趋势图表**：使用 Canvas 自绘折线图，保留并绘制最近 60 个采样点的流量曲线。绿线表示下载，红线表示上传，鼠标悬停可查看具体点位数值。
* **IP 信息与地理位置**：分别显示**本机**与**经由内核富强后**的出口 IPv4/IPv6 地址及归属地（国家/地区、ISP）。支持一键复制与密文隐藏切换。
* **自定义延迟测试**：支持对预设站点（Baidu / Bilibili / Google / GitHub / YouTube）测速，也可输入自定义 URL 测试；自定义地址会保存在浏览器本地。

> 内核版本一栏取自内核自身的版本接口。若内核未运行，会显示为「加载中」而非报错。

---

## 2. 富强管理 (Proxies)
负责节点选择、测速排序与正则过滤。

* **折叠与展开（手风琴效果）**：各分流策略组默认折叠。点击策略组卡片可展开下属的所有可用节点。
* **一键测速**：
  * **单节点测速**：点击节点卡片右侧的闪电图标，单独测试该节点延迟。
  * **组测速**：点击策略组卡片右上角的闪电图标，对该策略组内所有节点并行测速。
  * **全部测速**：点击页面顶部的「测试全部延迟」进行批量测速。
  * 三种方式都**强制限制并发为 10**，避免连接队列拥堵与后端负载过高。
* **延迟颜色标注**：默认绿色（≤150ms）、黄色（≤300ms）、红色（>300ms 或超时），阈值可在设置中调整。
* **排序与过滤**：点击右上角齿轮打开「代理设置」：
  * **排序方式**：默认 / 按名称 / 按延迟 / 按质量。选「按质量」会额外拉取节点质量评分。
  * **低/中延迟阈值**：自定义颜色分界（毫秒）。
  * **历史色块数量**：节点卡片上保留的延迟历史点数（5–10）。
  * **节点过滤正则**：按正则隐藏不需要的节点，默认 `(套餐|过期|流量|剩余|订阅|网站|教程)`。
  * **自动断开旧连接**：开启后，切换节点会自动断开该策略组内的旧连接，让新节点立即生效，省去手动重连。
* 以上设置均保存在**浏览器本地**，不影响其它设备。

## 3. 订阅配置 (Subscription)
进行参数管理、规则分流集设置，以及将配置渲染生成并写入内核。

* **全局网络端口**：配置混合富强端口（默认 7890）与外部控制面板端口（默认 9090）。
  * 取值为 `0` 表示禁用；填写时须在 `1025–65535` 之间，且各端口不可重复，否则面板会拦截并提示。
* **TProxy 端口**：透明富强专用端口（默认 7898）。
* **安全密钥**：保护内核 **TCP 外部控制端口**（`panel_port`）的密钥，供 MetaCubeXD / Zashboard 等外置面板直连内核时使用，带显隐切换。密钥不会下发给浏览器；面板自身与内核之间走 UNIX Socket（内核默认信任该来源），不使用该密钥。
* **规则集选择**：Base（标准基础分流）或 Full（详细增强分流）。该档位**只在融合模式下生效**，因此**切换模式下不显示**该下拉框（切换模式使用订阅自带规则）；隐藏期间取值仍保留在配置中并随「保存并应用」一并提交，切回融合模式后按原档位生成配置。
* **订阅模式切换**：融合模式（Merge）或切换模式（Switch），详见 [订阅工作模式](../config/subscription-modes)。
* **订阅列表**：每张卡片可单独编辑名称、链接、更新间隔、健康检查间隔与节点前缀，也可手动触发更新、查看流量与有效期信息。
* **保存并应用**：修改后必须点击此按钮，系统才会重新生成 `config.yaml` 并发送热重载指令，让内核无感切换。

## 4. 规则管理 (Rules)
展示当前生效的所有路由匹配规则。

* **检索过滤**：在顶部搜索框输入域名或关键字，检索命中的分流规则与出站策略。
* **规则临时开关**：每条规则右侧的开关可即时启用/停用该规则，无需修改底层模板。采用乐观更新，失败会自动回滚。
* **规则提供商 (Rule Providers)**：支持单个更新或一键全部更新（并发上限 3），并可查看各提供商的规则条数与最近更新时间。

---

## 5. 活动连接 (Connections)
监控所有正在通过富强的网络连接细节。

* **活跃连接与已关闭连接**：
  * **活跃连接**：实时计算每条连接的瞬时网速，支持排序与检索，点击可查看连接的完整元数据（来源/目标、命中规则、进程、链路等）。
  * **已关闭连接**：保留最近 100 条已断开的连接历史。
* **断开连接**：支持断开单条连接；顶部「断开所有连接」会强制内核断开当前全部连接并重新握手——切换节点后想让连接立即走新节点时很有用。
* **列设置**：可自定义表格显示哪些列，偏好保存在浏览器本地。

---

## 6. 日志查看 (Logs)
展示底层的 mi鸿蒙 运行日志。

* **级别过滤**：可按 debug / info / warning / error 过滤。
* **搜索**：支持关键字检索。
* **暂停/恢复滚动**：暂停后可自由上下翻阅历史日志；恢复后自动跟随最新日志。
* **清空**：一键清空本地缓冲（不影响内核侧日志）。
* **自动重连**：日志流断开后按 1s → 2s → 4s → … → 30s 指数退避自动重连，无需手动刷新。

## 7. 内核配置 (Config)
控制底层内核的运行方式，并集中放置各项维护操作。

### 内核控制
* **运行状态**：实时显示内核是「运行中」还是「已停止」。
  * 该状态由后端**主动推送**，内核若崩溃或被外部结束后会**立即变为「已停止」**，无需手动刷新。
* **启动 / 停止 / 重启**：一键控制内核进程。
* **更新**：可在面板内检查并更新 mi鸿蒙 内核（可选 Stable / Alpha 通道）。

### 常规参数
允许局域网连接、启用 IPv6、切换运行模式（规则 / 全局 / 直连）、调整日志等级。

### 端口设置
混合端口、HTTP 端口、SOCKS 端口、重定向端口、TProxy 端口。规则同「订阅配置」中的端口校验。

### 透明代理
* **启用 TUN**：由虚拟网卡接管系统层流量。协议栈可选 `System` / `gVisor` / `Mixed` / `Mips`。
  * 旁边的**齿轮按钮**可进入「TUN 高级设置」，配置 TUN 设备名与出口网卡（留空则自动检测）。修改即时生效。
* **启用 TProxy**：开启透明富强（详见 [TProxy 透明富强](../config/tproxy)）。
* **接管本机流量**：独立一行的开关，控制面板主机自身的出站流量是否也走富强。**启用 TProxy 期间该项不可修改**，需先关闭 TProxy。
* TUN 与 TProxy **互斥**：开启一方会自动关闭另一方。

### 高级运维
* **重载 Config 配置**：不重启内核热重载 `config.yaml`，长连接不中断。
* **清空 FakeIP 缓存** / **清空 DNS 缓存**：解决因 DNS 解析污染导致部分网页打不开的问题。
* **更新 GEO 数据库**：更新内核使用的 GeoIP 数据。

### 界面设置
* **界面语言**：简体中文 / English。
* **主题**：浅色 / 深色 / 魅惑紫 / 可爱粉 / 清新绿 / 冰海蓝 / 跟随系统。
* **默认启动页面**：可选择固定页面，或「记住上次页面」。

### DNS 查询
内置 DNS 解析测试工具：输入域名并选择类型（A / AAAA 等），点击查询即可查看内核解析出的具体 IP。在移动端点击输入框外的空白处会自动收起虚拟键盘。

---

## 8. 关于 (About)
在「配置」页右上角进入，展示：

* 面板版本（由后端在**编译期注入**，前端运行时读取）与内核版本；
* 更新日志与「检查更新」按钮，可直接更新面板自身。点按钮一律**无视后端 10 分钟缓存冷却**、即时回源查询（查询成功后会重新起算冷却，避免页面加载时的自动检查立刻重复请求），所以刚发布的版本手点一次就能看到；
* 开源仓库入口与技术特性说明。
